# 奇遇街 H5

原生 HTML、CSS、JavaScript 与 Three.js 制作的可交互 H5 演示。

入口 `index.html` 自动进入当前 3D 街景版本；`mall.html` 可查看商城入口。

- 整页连续滚动，顶部导航固定。
- 3D IP 陪逛、店铺切换与商品浏览。
- 七日到访奖励、优惠券、收藏和模拟下单。
- 底部弹窗统一标题，内容独立滚动。

商品、价格、奖励与订单均为演示数据，无账户、真实支付或发货。
浏览进度和奖励仅记录在访问者自己的浏览器中。

## 本地运行

```sh
python3 -m http.server 8770 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8770/`。没有安装或构建步骤。

## 发布与更新

GitHub Pages 使用 `main` 分支的仓库根目录发布。
修改 HTML、CSS、JavaScript 或素材后提交到 `main`，分享地址保持不变。
仓库仅包含当前 H5 所需文件，不包含历史模型、参考视频和个人工作文件。
